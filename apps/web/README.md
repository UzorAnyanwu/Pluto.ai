# apps/web

The single Next.js (App Router) application serving tenant dashboards, agency dashboards, and the
platform admin panel via role-based route groups (`(tenant)`, `(agency)`, `(platform-admin)`) — see
[`docs/architecture/01-system-architecture.md`](../../docs/architecture/01-system-architecture.md) §8
for why this is one app rather than three.

Not yet implemented — scaffolding lands in Phase 2 (Core Frontend).
